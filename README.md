# Árverésfigyelő – mobil app (PWA)

A privát NAV-alerts bot feedjét mutatja és ott menti a beállításokat.
Ez a repó **csak kódot** tartalmaz, adatot nem: a tételeket az app a GitHub API-n keresztül,
a telefonon tárolt tokennel olvassa a privát repóból.

Telepítés: Settings → Pages → Source: Deploy from a branch → main / (root).
Utána Chrome-ban nyisd meg az oldalt → ⋮ → Telepítés.
